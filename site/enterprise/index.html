Enterprise security review

Answers for the first security questionnaire

The current boundary states what is implemented, qualified and still pending rather than hiding those distinctions behind a generic security claim.

Identity and authorization

Viewer, Editor and Admin roles protect organization and project operations. Tokens are stored only as SHA-256 digests. OIDC organization mapping is part of the qualified 1.5.0 workflow; SAML is not currently claimed.

Audit and retention

Successful mutations create append-only audit events. Qualified managed workflows add immutable audit export, project policy and enforced retention.

Network and privilege boundary

The server binds to loopback behind NGINX with TLS 1.2/1.3 and HSTS. The server receives neither the Docker socket nor Linux capabilities; privileged execution stays in a separate agent.

Supply-chain controls

Release signatures, canonical manifests, provenance and an SPDX SBOM accompany the qualified artifacts. CI runs CodeQL, reachable-vulnerability analysis, fuzzing and Trivy scans.

Independent assessment status

An independent security review is planned. No completed external audit or certification is currently claimed.

    Define the boundary

    Name the protocol behavior, failure mode and property that cannot be violated.

  2. 02

    Select the qualified integration or execution path that matches the target boundary.

  3. 03

    Install and qualify

    Deploy the verified self-hosted distribution and record the tested version, commit and environment.

  4. 04

    Make it repeatable

    Place the scenario and its evidence into the team's release and review workflow.

Qualified baseline

Deliberately specific about deployment

The currently qualified Enterprise deployment target is Ubuntu 24.04 on amd64. The install preflight requires at least 15 GB free; 30 GB free is the recommended production baseline.

GCP can be used as an optional adapter, but it is not a required dependency. The customer path is provider-neutral and supports offline delivery.
